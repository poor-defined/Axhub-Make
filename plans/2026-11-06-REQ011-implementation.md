# REQ-011 实施计划

分支：`codex/reference-component-prd`。产品决策见《参考页面与组件图文引入 PRD》。

1. 参考页服务：项目隔离的 HTML / ZIP / 当前页面链接导入，缓存静态资源，提供列表与页面预览；复用 HTML 批注 bootstrap。
2. 图文服务：校验组件截图与来源；AI 在隔离的只读会话中生成说明，未知业务规则标记“待确认”；截图作为项目资源保存，确认后追加现有 Markdown PRD。
3. 批注入口：同一个输入框增加“引入说明”，只接受单组件/容器；截图后通过已有可信 iframe 通道交给宿主。
4. 宿主界面：增加“参考”Tab、导入与参考页列表；新增选择 PRD、手动 AI 生成、编辑/重新生成和确认追加对话框。
5. 集成验证：导入相对资源、项目隔离、截图与文本校验、重复追加、AI 失败与取消、已有批注与导出回归；构建并同步开发启动器。

执行方式：按 subagent-driven-development 分工实现独立服务与批注桥接，宿主负责界面集成与最终审查。不自动提交代码，完成后交用户验收。
