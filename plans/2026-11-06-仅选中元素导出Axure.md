# REQ-009：仅将选中元素导出到 Axure

日期：2026-11-06
状态：已实现并完成开发验证；用户于 2026-11-06 授权将当前版本打包提交。
开发分支：`codex/selected-elements-axure-export`，起点为已验收的 REQ-008 提交 `757f9e6`。
需求入口：[项目需求库](../docs/requirements/README.md)。

## 用户需求

“选择元素之后，支持仅将选中的元素导出到 Axure。”

结合已有 Command 多选能力，范围包含单选和多选。导出应以用户当前选择为边界，不包含未选择的同级元素或整页。选中容器时建议包含其内部可见内容，具体边界需验证并在操作提示中说明。

## 开发前能力与差距

`vendor/axhub-commentary/src/design-tool-export.ts` 已存在 `exportSelectionToDesignTool(tool, element)`，能以一个元素为根调用 `htmlToAxure` 并写入文本剪贴板。

现有函数只接收一个元素，不能据此认定 Command 多选已全部导出。管理端的 `handleCopyToAxure` 则从当前预览资源的 `#root` 采集，不能直接用于“仅导出选中范围”。两条复制路径最终交付方式也不同，需要确认统一方式或各自兼容性。

## 建议行为与边界

- 在元素选中状态提供“选中元素复制到 Axure”的入口，多选时展示目标数量。
- 单选只导出目标；多选导出整组选中目标，保持相对位置、层叠关系和可编辑性。
- 同时选中父容器及其子元素时去重，避免重复导出。
- 选择失效、无选择或导出期间页面变化时给出清楚反馈，避免退回整页导出。
- 对依赖父容器裁剪、样式或资源的元素，只携带还原所必需的数据，不把无关父级内容一起导出。
- 与 REQ-007 的 AI 整理能力共用管线，但 AI 输入和输出严格限制在选中范围。
- 与 REQ-008 的线框图规则一致：AI 生成和修改保持线框图风格；单纯复制不额外重绘原型。

本次入口为批注卡片的专用 Axure 按钮，直接可见，不依赖设计工具偏好；透明包装画板按去重后的根节点数量命名。AI 整理沿用 REQ-007 的项目偏好，用户可选择原始或整理版本。

## 所需代码调整

- 从共享选择状态获取完整的 `selectedElements` 快照，而非只读取最后一个 `selectedElement`。
- 扩展局部导出适配层，处理父子去重、多根节点、共享资源合并、节点 ID 冲突和坐标归一化。
- 为整个选择集合生成一致的层叠顺序，处理跨容器目标的顺序和裁剪约束。
- 明确局部导出使用现有文本剪贴板还是 Axure Bridge，并进行真实粘贴验证。
- 接入受限于选择范围的 AI 树整理与结果预览。

## 本次实施设计

在当前工作区切换分支以继续使用桌面绑定的测试环境。启动器锁定新分支，仍调用仓库内脚本、使用独立开发状态与 ACP，启动前重建批注包。

复用批注卡片的 Axure 导出按钮，提示选中数量及容器包含子元素。操作从当前选择取得完整快照，不从历史批注或页面根节点恢复目标。空选择、任一失效/锁定目标或采集期间布局变化均报错，不退回整页或部分导出。

方案比较：采集共同祖先会泄露未选中兄弟节点；克隆到临时容器可能丢失继承、布局与裁剪；本次采用各去重根节点独立采集后合并 payload。保持原 DOM 和计算样式；选中容器包含内部可见内容；父子同时选择只保留父根。多根结果合并为透明选区画板，节点采用同一画板坐标，保留 mask/SVG 子树及共享图像资源，重分配节点 ID 避免每次采集从相同 ID 开始造成冲突。仅合并已采集选区，REQ-007 的 AI 整理预览不会收到整页数据。

## 开发验证与边界

- 相关回归覆盖真实选择回调、锁定/失效/空选择、父子去重、多根坐标与 mask/SVG 数据平移、资源与 ID 合并、真实采集器和 AI 整理输入。根及后代的几何、文本或 DOM 成员发生变化时中止；任一根返回空内容也中止。
- 共同祖先不会作为采集目标。只对去重后的根采集，裁剪信息由既有采集器的 mask 数据携带，不采集未选中的兄弟内容。
- 常见绘制顺序覆盖负 z-index、普通流、浮动、inline、positioned(auto/0)、正 z-index。非独立 stacking context 根的后代与其它选区交错时，明确提示选择共同容器或分别导出，避免静默改变遮挡关系。
- 真实采集器会跳过 SVG 内部 path/g/嵌套 svg 根。真实 core 回归确认了此行为；本功能明确阻止其独立导出，不扩大为整个 SVG。显式选中完整 SVG 容器及其子 path 时先去重，保留容器。
