# 统一页面骨架加载

## 需求描述

将页面内容尚未就绪时的空白、居中加载文字或单独转圈统一为 Skeleton Loaders。根据预览、文档、列表、表格、画布等内容布局显示骨架，支持窄屏、暗色和减少动态效果。按钮提交、上传进度、错误与空状态继续使用其各自反馈。

## Implementation Steps & Status

- [x] 创建共享布局与样式，供 React 页面、生成等待页和独立模板复用。
- [x] 替换管理端内容、列表、资源与弹窗数据读取区域的页面加载反馈。
- [x] 更新后续原型生成等待页；通过预览启动时的受限临时遮罩兼容已有旧等待页，不改原型源文件。
- [x] 替换模板首屏和画布／文档初次加载效果。
- [x] 检查原型 iframe 的首屏加载与参考页加载，保留错误和操作能力。
- [x] 运行相关回归、类型检查及构建，更新开发服务。

## Testing Checklist

- [x] 骨架具有 status、aria-busy 和可读说明，装饰内容对辅助技术隐藏。
- [x] 仅识别应用生成的确切旧等待占位，真实原型和空状态不被误遮罩，生成内容替换后自动移除遮罩。
- [x] 切换／卸载和错误路径不会遗留遮罩。
- [x] 页面布局在桌面和窄屏可用，动画尊重 prefers-reduced-motion。
- [x] 用独立浏览器验证主要布局与旧等待页切换，不修改真实项目原型。
- [x] 无新增网络请求、计时等待或 AI 执行。

## 验证结果

- 17 个定向测试文件、218 项测试通过；服务端类型检查和完整管理端构建通过。
- 5 份构建 HTML 首屏壳均已展开骨架，未留下未解析标记；便携客户端有独立首屏骨架。
- 独立浏览器验证桌面、390px 窄屏无横向溢出、暗色与减少动态效果。
- 直接加载实际管理 bootstrap（不调用 renderComponent）验证普通客户端自动兼容旧等待页；重复安装不产生多个遮罩，内容替换、可见性变化和根节点移除会自动撤下。
- 仅临时 DOM 与测试目录操作，没有改写真实项目原型、PRD 或发起 AI 任务。
- 全量前端 TypeScript 检查仍存在既有类型／未使用变量问题；本次新增骨架模块的定向检查没有新错误。
