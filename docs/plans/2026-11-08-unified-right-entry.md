# 统一右侧入口

将批注列表、快捷键与原型已有的页面目录、文档目录、设置收拢到同一条右侧工具栏。已有标注工具栏存在时，批注运行时在其设置按钮前挂载自己的操作组；保留工具栏原有自定义操作、拖动、自动隐藏与主题行为。页面没有标注工具栏时，提供同样的批注与快捷键操作组。

打开批注列表时关闭原工具栏展开的目录和设置；点击原工具栏入口时关闭批注列表。批注面板在右侧保留工具栏宽度，打开后仍可直接切换。组件批注气泡同步避让面板。页面切换、工具栏延迟挂载、重新挂载与退出批注时，移除旧挂载点及监听器，防止重复入口。沿用批注列表现有加载骨架、错误重试和空状态。

实现位于 `vendor/axhub-commentary/src/ui/runtime/right-entry.tsx` 与 `annotation-toolbar-bridge.ts`；后者适配依赖包的 Shadow DOM 工具栏，避免替换 `toolbarActions` 而覆盖其他功能。

验证：运行 `pnpm exec vitest run src/vendor/axhub-commentary`，构建 `pnpm vendor:build:commentary`。测试覆盖入口操作、原有自定义操作保留、互斥切换、工具栏卸载/重挂载与清理。

验证结果：批注、原型桥接、HTML 与 Markdown 边界相关的 19 个测试文件共 211 项测试通过；批注依赖图的严格 TypeScript 检查、运行时构建及 `git diff --check` 通过。跨 Shadow DOM 的入口节点已纳入编辑器 UI 识别，防止焦点在工具栏按钮时触发删除、保存或方向键操作。独立代码审查未发现剩余阻塞问题。
