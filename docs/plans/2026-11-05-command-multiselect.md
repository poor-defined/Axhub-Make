# Command 多选元素

在现有元素批注工具中，Command 点击切换元素的选中状态；普通点击保持现有单选流程，Esc 清空整组。最后选中的元素继续作为浮动输入框的锚点，其他元素保留选中轮廓。

实现时保留 `selectedElement` 兼容现有面板，并增加 `selectedElements` 集合。事件拦截器必须在取消原选择前处理 Command 点击。失效节点不参与选择，锁定节点仍不可选择，文字选区模式维持原行为。

多选写入同一条批注时，为每个目标沿用现有批注存储及截图机制；发送操作覆盖整组，AI 上下文包含全部选择。普通文本、样式编辑仍作用于当前锚点，不引入批量样式编辑。

验证覆盖追加、切换、取消最后一个元素、单选替换、Esc、失效节点、锁定节点，以及整组批注的目标解析。维护源文件和实际被导入的 vendor 构建产物保持一致。
